Paper Tigers

  • “没有 AI 就没有价值”：不成立。当前核心价值是安全集中保存、快速查找和就诊前资料包。
  • “必须先做 App”：不成立。网页足够验证上传、整理、导出和订阅意愿。
  • “功能少用户不会付费”：未必。若资料包解决真实就诊痛点，家庭版仍可验证付费。

    • Elephants in the Room

    1. 旧版文档和原型里 AI/OCR 承诺较多，必须主动降级，否则用户预期会错位。
    2. “中国大陆用户”与现有 Vercel/Resend 等服务之间可能存在长期生产适配问题，需要明确当前只是验证还是公开商业化。
    3. 医疗健康数据合规成本高，不能等到用户量起来后再补权限、删除、审计和备案。

    Data Permission Baseline

    Principles

    • 默认拒绝。
    • 每份病历、药品、指标、待办、资料包都必须有 member_id。
    • 后端根据资源真实归属鉴权，不接受前端声明的成员归属。
    • 成年成员资料必须主动授权。
    • 客服和后台默认无权读取病历正文和原文件。
    • 删除、导出、授权、分享都必须写审计。

    Roles

    RoleScopeAllowed SELF本人档案完整控制本人资料 GUARDIAN未成年人档案管理未成年人资料 MANAGER获授权家人管理资料、药品、提醒；导出/删除需配置 CONTRIBUTOR协助录入者上传和修改资料，不能导出或分享 VIEWER只读家人查看授权范围，默认不能下载原件 SUPPORT客服默认无医疗资料权限

    MVP Privacy Center

  • 查看隐私政策和服务协议。
  • 查看敏感健康信息处理说明。
  • 导出结构化数据和原文件。
  • 删除单份资料。
  • 撤销家庭授权。
  • 注销账号入口。
  • 查看第三方服务清单。

    • Launch Checklist

    Product

  • [ ] 首页主入口改为“今日”和“我要去看医生”。
  • [ ] 移除 AI/OCR 作为 MVP 承诺的文案。
  • [ ] 所有药品页面显示“不提供用药建议”边界。
  • [ ] 就诊资料包 PDF 结构固定且可预览。
  • [ ] 免费版和家庭订阅权益不锁死已有数据。

    • Engineering

  • [ ] 生产环境验证码不明文展示。
  • [ ] 上传文件私有存储，不使用公开 ACL。
  • [ ] 每份医疗资源带 member_id 并后端鉴权。
  • [ ] 核心闭环埋点已接入：注册、建档、上传、归档、资料包、PDF 导出。
  • [ ] 埋点属性白名单已接入，禁止病历正文、药品名称、诊断名、搜索词原文进入分析系统。
  • [ ] 越权测试覆盖读取、修改、下载、导出、删除。
  • [ ] 审计日志不记录病历正文、验证码、Token、签名 URL。
  • [ ] 用户可导出、删除和注销。
  • [ ] PDF 导出失败可重试且不会生成脏数据。

    • Security & Compliance

  • [ ] 隐私政策和服务协议联系方式替换为真实联系方式。
  • [ ] 敏感健康信息单独同意。
  • [ ] 成年成员授权和撤销流程可用。
  • [ ] 完成第三方服务清单：邮箱、云存储、日志、监控等。
  • [ ] 评估 ICP 备案、公安备案和中国大陆部署。
  • [ ] 完成个人信息保护影响评估草案。
  • [ ] 错误监控脱敏。

    • User Testing

  • [ ] 真实用户完成：注册 -> 建档 -> 上传 -> 分类 -> 添加药品 -> 记录指标 -> 生成 PDF -> 删除。
  • [ ] 记录每一步耗时和卡点。
  • [ ] 用埋点看板复核每一步转化率和失败错误码。
  • [ ] 询问用户：PDF 是否能直接给医生看。
  • [ ] 询问用户：是否愿意为家庭版订阅付费。

    • Go / No-Go

    Go 条件：

  • [ ] 一次完整端到端流程跑通。
  • [ ] PDF 资料包可用性达到封测要求。
  • [ ] 权限和越权测试通过。
  • [ ] 删除和导出能力可用。
  • [ ] 隐私政策、服务协议、敏感信息同意文本齐备。

    • No-Go 条件：

  • [ ] 仍有 AI/OCR 误导性承诺。
  • [ ] 家庭成员数据可能串档。
  • [ ] 用户无法删除或导出资料。
  • [ ] PDF 资料包不能覆盖本次就诊目的、近期情况、相关资料、当前用药和关键指标。
