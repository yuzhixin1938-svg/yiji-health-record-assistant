测试场景

医记测试场景

Source：新版 PRD 和用户故事 Coverage：happy path / edge cases / errors / security / privacy

Scenario 1：新用户完成本人建档

Tests：邮箱登录、本人档案 Preconditions：用户邮箱未注册 User role：患者本人

StepActionExpected Result
1输入邮箱并获取验证码验证码发送成功
2输入正确验证码登录成功并进入建档流程
3填写昵称、性别、出生年月表单校验通过
4保存档案创建本人档案，进入档案补全任务

Priority：Critical

Scenario 2：验证码异常处理

StepActionExpected Result 1输入错误验证码返回错误提示，不创建会话 2输入过期验证码返回过期提示 3连续多次请求验证码触发限流提示

Priority：High

Scenario 3：上传并手动归档病历资料

StepActionExpected Result 1上传一张检查报告图片文件上传成功，状态为待归档 2填写资料类型、医院、日期、标签字段保存成功 3点击归档资料进入对应成员时间线 4查看归档反馈显示“已归档到 [成员] > [类型] > [日期]”

Priority：Critical

Scenario 4：上传失败

StepActionExpected Result 1上传超大文件阻止上传并提示大小限制 2上传不支持格式阻止上传并提示支持格式 3上传中断不生成可见的完整资料，允许重试

Priority：High

Scenario 5：搜索和时间线

StepActionExpected Result 1上传多份不同医院资料多条资料归档成功 2搜索医院名返回匹配资料 3按资料类型筛选只展示该类型资料 4查看时间线按日期倒序展示

Priority：High

Scenario 6：添加药品和用药提醒

StepActionExpected Result 1添加药品名称、规格和用法用量原文药品保存成功 2设置每日提醒时间今日待办出现对应用药事项 3停用药品后续提醒停止

Priority：Critical

Scenario 7：药品安全边界

StepActionExpected Result 1用户查看药品详情显示“不提供用药建议”边界提示 2用户未填写用法用量系统不自动生成剂量 3用户添加多个药品系统不判断相互作用或替代关系

Priority：Critical

Scenario 8：记录指标

StepActionExpected Result 1记录血压 128/82保存为血压记录 2选择来源为手动记录来源显示正确 3查看历史记录按时间展示，不给出诊断判断

Priority：High

Scenario 9：生成就诊资料包 PDF

StepActionExpected Result 1点击“我要去看医生”进入资料包生成流程 2选择本人和本次就诊目的进入资料选择 3勾选相关资料、药品、指标进入近期情况补充 4填写近期症状和想问医生的问题可预览资料包 5导出 PDFPDF 生成成功且包含完整资料

Priority：Critical

Scenario 10：家庭成员数据隔离

StepActionExpected Result 1创建家庭成员 A 和 B成员创建成功 2给 A 上传资料资料只出现在 A 名下 3切换到 B不展示 A 的资料 4直接请求 A 的资料 ID未授权用户返回 403 或 404

Priority：Critical

Scenario 11：授权撤销

StepActionExpected Result 1授权家人查看资料家人可按授权范围查看 2撤销授权家人立即失去访问权限 3家人刷新旧页面访问失败

Priority：Critical

Scenario 12：数据导出和删除

StepActionExpected Result 1用户请求导出数据生成结构化数据和原文件导出 2用户删除单份资料资料不再可见，相关待办/资料包引用更新 3用户申请注销账号进入二次确认和删除流程

Priority：Critical
