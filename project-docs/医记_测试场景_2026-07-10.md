# 医记测试场景

**Source**：新版 PRD 和用户故事  
**Coverage**：happy path / edge cases / errors / security / privacy  

## Scenario 1：新用户完成本人建档

**Tests**：邮箱登录、本人档案  
**Preconditions**：用户邮箱未注册  
**User role**：患者本人

| Step | Action | Expected Result |
|---|---|---|
| 1 | 输入邮箱并获取验证码 | 验证码发送成功 |
| 2 | 输入正确验证码 | 登录成功并进入建档流程 |
| 3 | 填写昵称、性别、出生年月 | 表单校验通过 |
| 4 | 保存档案 | 创建本人档案，进入档案补全任务 |

**Priority**：Critical

## Scenario 2：验证码异常处理

| Step | Action | Expected Result |
|---|---|---|
| 1 | 输入错误验证码 | 返回错误提示，不创建会话 |
| 2 | 输入过期验证码 | 返回过期提示 |
| 3 | 连续多次请求验证码 | 触发限流提示 |

**Priority**：High

## Scenario 3：上传并手动归档病历资料

| Step | Action | Expected Result |
|---|---|---|
| 1 | 上传一张检查报告图片 | 文件上传成功，状态为待归档 |
| 2 | 填写资料类型、医院、日期、标签 | 字段保存成功 |
| 3 | 点击归档 | 资料进入对应成员时间线 |
| 4 | 查看归档反馈 | 显示“已归档到 [成员] > [类型] > [日期]” |

**Priority**：Critical

## Scenario 4：上传失败

| Step | Action | Expected Result |
|---|---|---|
| 1 | 上传超大文件 | 阻止上传并提示大小限制 |
| 2 | 上传不支持格式 | 阻止上传并提示支持格式 |
| 3 | 上传中断 | 不生成可见的完整资料，允许重试 |

**Priority**：High

## Scenario 5：搜索和时间线

| Step | Action | Expected Result |
|---|---|---|
| 1 | 上传多份不同医院资料 | 多条资料归档成功 |
| 2 | 搜索医院名 | 返回匹配资料 |
| 3 | 按资料类型筛选 | 只展示该类型资料 |
| 4 | 查看时间线 | 按日期倒序展示 |

**Priority**：High

## Scenario 6：添加药品和用药提醒

| Step | Action | Expected Result |
|---|---|---|
| 1 | 添加药品名称、规格和用法用量原文 | 药品保存成功 |
| 2 | 设置每日提醒时间 | 今日待办出现对应用药事项 |
| 3 | 停用药品 | 后续提醒停止 |

**Priority**：Critical

## Scenario 7：药品安全边界

| Step | Action | Expected Result |
|---|---|---|
| 1 | 用户查看药品详情 | 显示“不提供用药建议”边界提示 |
| 2 | 用户未填写用法用量 | 系统不自动生成剂量 |
| 3 | 用户添加多个药品 | 系统不判断相互作用或替代关系 |

**Priority**：Critical

## Scenario 8：记录指标

| Step | Action | Expected Result |
|---|---|---|
| 1 | 记录血压 128/82 | 保存为血压记录 |
| 2 | 选择来源为手动记录 | 来源显示正确 |
| 3 | 查看历史记录 | 按时间展示，不给出诊断判断 |

**Priority**：High

## Scenario 9：生成就诊资料包 PDF

| Step | Action | Expected Result |
|---|---|---|
| 1 | 点击“我要去看医生” | 进入资料包生成流程 |
| 2 | 选择本人和本次就诊目的 | 进入资料选择 |
| 3 | 勾选相关资料、药品、指标 | 进入近期情况补充 |
| 4 | 填写近期症状和想问医生的问题 | 可预览资料包 |
| 5 | 导出 PDF | PDF 生成成功且包含完整资料 |

**Priority**：Critical

## Scenario 10：家庭成员数据隔离

| Step | Action | Expected Result |
|---|---|---|
| 1 | 创建家庭成员 A 和 B | 成员创建成功 |
| 2 | 给 A 上传资料 | 资料只出现在 A 名下 |
| 3 | 切换到 B | 不展示 A 的资料 |
| 4 | 直接请求 A 的资料 ID | 未授权用户返回 403 或 404 |

**Priority**：Critical

## Scenario 11：授权撤销

| Step | Action | Expected Result |
|---|---|---|
| 1 | 授权家人查看资料 | 家人可按授权范围查看 |
| 2 | 撤销授权 | 家人立即失去访问权限 |
| 3 | 家人刷新旧页面 | 访问失败 |

**Priority**：Critical

## Scenario 12：数据导出和删除

| Step | Action | Expected Result |
|---|---|---|
| 1 | 用户请求导出数据 | 生成结构化数据和原文件导出 |
| 2 | 用户删除单份资料 | 资料不再可见，相关待办/资料包引用更新 |
| 3 | 用户申请注销账号 | 进入二次确认和删除流程 |

**Priority**：Critical

## Coverage Matrix

| Requirement | Happy Path | Edge Cases | Error Handling | Security/Privacy Notes |
|---|---|---|---|---|
| 邮箱登录 | Scenario 1 | Scenario 2 | 验证码错误/过期/限流 | 不展示生产验证码 |
| 本人建档 | Scenario 1 | 缺少可选信息 | 表单校验 | 默认本人归属 |
| 病历上传 | Scenario 3 | Scenario 4 | 上传失败/格式错误 | 原文件私有存储 |
| 分类归档 | Scenario 3 | 字段修改 | 保存失败重试 | 修改写审计 |
| 搜索时间线 | Scenario 5 | 多成员筛选 | 无结果提示 | 不跨成员泄露 |
| 药品提醒 | Scenario 6 | 停用药品 | 无提醒权限 | 不自动建议剂量 |
| 指标记录 | Scenario 8 | 不同单位 | 输入错误 | 不做诊断 |
| 就诊资料包 | Scenario 9 | 无资料状态 | PDF 失败重试 | 导出前鉴权 |
| 家庭权限 | Scenario 10/11 | 授权撤销 | 403/404 | 默认拒绝 |
| 数据权利 | Scenario 12 | 删除后恢复 | 异步失败重试 | 删除证明不含正文 |
